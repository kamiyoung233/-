校园网络助手 ─ CampusNetHelper v0.1
========================================

天津科技大学校园网自动登录工具
基于深澜 Portal 认证系统

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【功能】

  • 一键登录 ── 输入学号密码，自动完成 Portal 认证
  • 状态显示 ── 实时查看校园网连接状态、IP、延迟
  • 静默模式 ── 后台自动登录，成功不打扰，失败有提示
  • 运行日志 ── 完整记录登录过程，方便排查问题
  • 开机自启 ── 支持通过 Windows 计划任务自动启动

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【使用方式】

  1. 双击 CampusNetHelper.exe 启动图形界面
  2. 输入学号和密码，点击登录即可

  静默模式（后台自动登录）：
    在命令行中运行：
    CampusNetHelper.exe --silent

  查看帮助：
    CampusNetHelper.exe --help

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【文件说明】

  CampusNetHelper.exe    主程序
  _internal/             Python 运行环境（程序依赖）
  config/config.json     配置文件（首次运行自动生成）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【系统要求】

  • Windows 7 / 8 / 10 / 11
  • 校园网环境下使用（深澜 Portal 认证）
